# Commands

All commands start with `/warcrest`, or the short `/wc`. The old `/imperium` and `/imp` still work.

| Command | What it does |
| --- | --- |
| `/warcrest` | Open or close the addon |
| `/warcrest raids` | Raids tab |
| `/warcrest dkp` | DKP tab |
| `/warcrest kills` | Kills and Top Head Hunters |
| `/warcrest wanted` | Wanted list |
| `/warcrest card [name]` | A guild member's player card (yours if no name) |
| `/warcrest wishlist` | The guild's loot wishlist, and yours |
| `/warcrest achievements` | Your achievements and title |
| `/warcrest addon` | Who has the addon, and who's out of date |
| `/warcrest auction [item] [min bid]` | Auction an item to your raid (officers) |
| `/warcrest test` | Show a test alert (a different kind each time) |
| `/warcrest sound` | Turn alert sounds on or off |
| `/warcrest warn` | Turn the center-screen alert on or off |
| `/warcrest quiet` | Hold alerts during combat, on or off |
| `/warcrest minimap` | Show or hide the minimap button |
| `/warcrest sync` | Catch up on guild history now |
| `/warcrest recap` | Last week's guild recap |
| `/warcrest recap now` | This week's recap so far |
| `/warcrest updates` | What changed in recent versions |
| `/warcrest versions` | Ask guildmates which version they have |
| `/warcrest version` | Your version, plus any problems the addon has hit |
| `/warcrest debug` | Show error details in chat |
